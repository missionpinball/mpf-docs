# Installing MPF Monitor

As of September 2026, the current stable version of MPF Monitor is `1.0.0`.

MPF Monitor version numbers are unrelated to MPF game version numbers.
It is fine to run MPF Monitor version 0.57.2, for instance, alongside an MPF game using 0.80 or newer.
Instead, the important version is the BCP protocol version.

You can install it via `pip` (or `pip3`, or however you installed MPF).

``` doscon
$ pip install mpf-monitor
```

Old versions of monitor can be found on [Github](https://github.com/missionpinball/mpf-monitor/tags)
and [Pypi](https://pypi.org/project/mpf-monitor/#history).
